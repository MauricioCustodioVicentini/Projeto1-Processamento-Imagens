# Projeto 1 - Processamento de Imagens

Projeto desenvolvido para a disciplina de Computação Visual da Universidade Presbiteriana Mackenzie.

O objetivo do projeto é desenvolver uma aplicação em linguagem C utilizando SDL3 e SDL_image para carregamento, processamento e análise de imagens.

## Tecnologias previstas

- Linguagem C
- SDL3
- SDL_image
- SDL_ttf
- GCC
- Makefile

## Estrutura inicial

- `src/`: código-fonte da aplicação
- `assets/fonts/`: fontes utilizadas pela interface
- `samples/`: imagens utilizadas durante os testes
- `docs/`: documentação complementar do desenvolvimento
